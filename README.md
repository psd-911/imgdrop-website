## 🌟 Key Features

- **100% Private & Local**: Processing runs entirely on your browser CPU via HTML5 Canvas. Zero images or PDFs are uploaded to any backend cloud servers.
- **Image Converter**: Instant batch conversion between `WebP`, `JPG`, `PNG`, and `AVIF`.
- **Target Size Compressor**: Compress images to exact `20 KB` (Exam portals), `50 KB` (Passport photos), or `100 KB` (Visa forms).
- **Interactive Visual Cropper**: Drag-and-drop crop frame with `1:1`, `16:9`, `9:16 Reels`, `4:3`, and `3:2` ratios with zoom & pan.
- **Images to PDF**: Combine multiple images and scans into a single multi-page PDF document locally.
- **Zero Server Costs**: Static site architecture deployable on Vercel or Cloudflare Pages for $0/month.

## 🚀 1-Click Local Run

```bash
# Python 3
python -m http.server 8000
# Then visit http://localhost:8000
```

Or double-click `run_site.bat` on Windows.

---

## 🌐 Deploy to Vercel in 60 Seconds

1. Fork or push this repository to GitHub.
2. Go to [Vercel.com](https://vercel.com) and click **"New Project"**.
3. Select this repository and click **Deploy**.
4. Attach your custom domain in **Project Settings ➔ Domains**.
